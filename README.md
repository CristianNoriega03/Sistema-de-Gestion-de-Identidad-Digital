#Contextualizacion  

Actualmente muchas entidades gubernamentales ofrecen tramites por internet, para acceder a estos servicios se requiere de la verificación de la identidad del ciudadano, si la identificación no es suficientemente segura existe el riesgo de suplantación de identidad y acceso no autorizado. Diferentes entidades pueden manejar sistemas y mecanismos de autenticación diferentes por eso en este caso surge la necesidad de una solución de identidad digital segura que permita autenticar a las personas y controlar que servicios puede usar cada una. 

 

#Descripción 

Sistema web de gestión de identidad digital para servicios gubernamentales. La plataforma permitirá registrar usuarios, verificar su identidad mediante autenticación multifactor y controlar acceso a los servicios según los roles y permisos asignados. El sistema busca ofrecer una forma más segura de gestionar la identidad de los ciudadanos reduciendo el riesgo de suplantación y accesos no autorizados. 

 

#Que problema va a solucionar? 

Reducir el riesgo de suplantación de identidad y accesos no autorizados a servicios. 

 

#Alcance  

Crud de ciudadanos, autenticador multifactor , gestión de citas para tramite de renovación de cédula por perdida, consultas y cancelación de citas, administración de permisos y roles. No incluye integración con la registraduría, bases de datos gubernamentales ni servicios reales externos, los procesos serán simulados para la entrega del proyecto. 

 

#Objetivo general 

Desarrollar un sistema web de gestión de identidad digital que permita autenticar usuarios, administrar roles y permisos y controlar de forma segura el acceso a un servicio gubernamental simulado. 

 

#Objetivos específicos 

Diseñar e implementar un sistema web para el registro y gestión de ciudadanos. 

Implementar un mecanismo de autenticación multifactor para fortalecer la seguridad del acceso de los usuarios. 

Establecer un esquema de roles y permisos para controlar el acceso a las funcionalidades del sistema. 

Gestionar las citas para el trámite simulado de renovación de cédula por pérdida, incluyendo su consulta y cancelación. 

Aplicar buenas prácticas de seguridad en la gestión de usuarios, credenciales y acceso a la información.
